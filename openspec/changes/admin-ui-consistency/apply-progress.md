Method: a throw-away script converted the canonical block (`div > Label + control + error p`) to `FormField` and I finished the irregular sites by hand. Composite controls use the render-prop child. Deviation from design Decision 11: for `Controller` fields, `FormField` wraps the `Controller` and the render-prop child returns it (the `a11y` props close over into `render`), instead of placing `FormField` inside `render`. The result is identical; the error comes from the `errors` object either way. Hints that sat next to a control ("Dejalo en 0...", "Stock resultante...", stock/equipment help text, file size) moved into `FormField.description`.
